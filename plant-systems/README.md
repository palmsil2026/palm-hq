โค้ดจริงของระบบขาย-โรงงานทั้งหมด **ไม่อยู่ใน repo นี้อีกต่อไป** — ย้ายไปที่:

**https://github.com/palmsil2026/origin-hq** (private)

| โฟลเดอร์ใน origin-hq | โปรเจกต์ GAS | แอป |
|---|---|---|
| `sales-app/` | Sale System | ละกอน เซลส์ (ทีมเซลล์/รถเร่) |

| `lakon-order/` | LIFF สั่งน้ำ | สำเนาแอปลูกค้า (ของจริงใน repo นี้ยังเป็น `index.html` ที่ root — รอ reconcile) |

## ทำไมย้าย

หลักการของคุณปาล์ม: **"ระบบแยกออกจากกัน แต่ดาต้าซิงก์กันเหมือนเป็นหนึ่งเดียว"**
- repo นี้ (`palm-hq`) = ศูนย์บัญชาการส่วนตัว: ทีม AI เลขา ทุกธุรกิจ + เรื่องส่วนตัว
- `origin-hq` = ระบบปฏิบัติการโรงน้ำโดยเฉพาะ — พังฝั่งไหน อีกฝั่งไม่ล้มตาม
- จุดซิงก์เดียวคือ **Google Sheets ของโรงน้ำ**: แอปผู้บริหาร/เลขาอ่านแบบ read-only ผ่าน
  Script Properties `PLANT_SHEET_ID` เหมือนเดิมทุกอย่าง (ห้ามดึงคอลัมน์ PIN เช่นเดิม)

## สำหรับทีม AI

- งานแก้โค้ดโรงน้ำ → ทำใน `origin-hq` (มี `DEPLOY.md` อธิบายการ push ขึ้น GAS ด้วย clasp)
- งานวิเคราะห์ข้อมูลโรงน้ำ → อ่านชีตผ่าน `PLANT_SHEET_ID` ตามเดิม ไม่ต้องแตะโค้ด
- ห้ามสร้างสำเนาโค้ดโรงน้ำกลับมาไว้ใน repo นี้อีก — สองสำเนา = แตกกันแน่นอน (เคยเกิดแล้ว)
