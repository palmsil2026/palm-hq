# 🧪 ชุดทดสอบคุณเลขา

โหลด `secretary/Code.gs` ตัวจริงขึ้นมารันในเครื่อง แล้วจำลองไลน์ ชีต Drive แอปบัญชี และสมอง Claude ทั้งหมด
**ไม่แตะของจริง ไม่ส่งไลน์ ไม่เสียค่า API**

| ไฟล์ | คืออะไร |
|---|---|
| `harness.js` | ตัวจำลอง GAS, LINE, Drive และแอปบัญชี |
| `unit.test.js` | เทสต์เส้นทางในโค้ด (คำสั่ง สิทธิ์ กลุ่มบิล ล้างข้อความ ฯลฯ) |
| `issue.test.js` | 🩺 หมอแอป: แท็กคุณปาล์ม → เคส AppIssues → API issueFeed/issueClaim/issueSave (ชีตจำลอง) — `unit.test.js` เรียกต่อท้ายให้เอง |
| `scenarios.js` | **ข้อสอบสถานการณ์** มีทั้งข้อที่คิดขึ้นเองและข้อที่ดัดแปลงจากแชทจริงใน `SecretaryLog` |
| `brain-eval.js` | ตัวคุมสอบ รันข้อสอบผ่านโค้ดจริง ส่งข้อที่ต้องคิดให้สมอง แล้วตรวจคำตอบสุดท้ายที่จะออกไลน์ |

## รัน

```bash
node secretary/test/unit.test.js                  # เทสต์เส้นทาง
node secretary/test/brain-eval.js check-routes    # ข้อสอบส่วนที่โค้ดตอบเอง + เช็คว่าข้อที่ต้องคิดไปถึงสมองจริง
node secretary/test/brain-eval.js dump /tmp/x     # ดึง prompt จริงที่จะส่งให้สมอง (ไว้ให้โมเดลสวมบทตอบ)
node secretary/test/brain-eval.js grade ans.json  # เอาคำตอบสมอง {id: ข้อความ} มาวิ่งผ่านโค้ดจริงแล้วตรวจ
ANTHROPIC_API_KEY=… node secretary/test/brain-eval.js live   # ถามสมองจริง (รุ่นเดียวกับ MODEL) — เสียค่า API
```

GitHub รันให้เองโดยอัตโนมัติ:
- **ทุก PR ที่แตะ `secretary/`**: workflow `Test secretary`
- **ก่อน deploy ทุกครั้ง**: ถ้าเทสต์ล้ม จะไม่ส่งโค้ดขึ้น GAS

## เมื่อเลขาตอบพลาดในไลน์จริง → เพิ่มข้อสอบ 1 ข้อเสมอ

1. คัดลอกข้อความที่พิมพ์ คำตอบของเลขา และสิ่งที่ควรเกิด มาบอกในแชท palm-hq
2. เพิ่ม 1 ข้อใน `scenarios.js` (ขึ้นต้น id ด้วย `R`) แล้ว**เปลี่ยนชื่อลูกค้า เบอร์ และตัวเลขเงินเป็นของสมมติ** เพราะ repo นี้ใครเปิดก็เห็น
3. แก้ prompt หรือโค้ด แล้วรันชุดสอบใหม่ทั้งชุด ต้องผ่านข้อใหม่และข้อเก่าทุกข้อ ห้ามแก้ข้อหนึ่งแล้วไปพังอีกข้อ
4. คำสั่งใหม่ของเลขา: ต้องลงทะเบียนใน `SEC_COMMANDS` ด้วย สมองจะได้เรียกเองได้จากภาษาพูด และต้องเพิ่มข้อสอบแบบภาษาพูดอย่างน้อย 1 ข้อ
