# 🗺️ แผนที่ระบบทั้งหมด (Systems Map)

> ไฟล์อ้างอิงกลางสำหรับทีม AI ทุกตัว โดยเฉพาะ `coder` และ `data`
> **กฎเหล็ก: ก่อนแตะโค้ดทุกครั้ง ต้องรู้ก่อนว่างานนี้เป็นของระบบไหน** — ถ้าใบงานไม่ระบุ ให้ถามกลับก่อน อย่าเดา
> เพราะแต่ละระบบเป็นคนละไฟล์ คนละโปรเจกต์ GAS คนละ deployment — แก้ผิดตัว = พังของจริงที่ทีมใช้อยู่

## ⚠️ กันพลาดยอดฮิต

1. **`Code.gs` มี 2 ไฟล์คนละระบบ** — `secretary/Code.gs` (เลขา) กับ `olddays/gas/Code.gs` (คาเฟ่) เช็ค path ให้ชัวร์ก่อนแก้ทุกครั้ง
2. **Deploy แยกกันหมด** — แก้โค้ด GAS ระบบไหน ต้อง deploy ที่โปรเจกต์ GAS ของระบบนั้น และใช้วิธี **Manage deployments → ✏️ → New version เท่านั้น** (ห้าม "New deployment" — URL จะเปลี่ยนแล้วท่อพัง: LINE webhook, Routine, ลิงก์บอร์ด)
3. **หน้าเว็บ Old Days อัปเดตผ่าน `main` เท่านั้น** — โค้ดที่ยังไม่ merge เข้า `main` จะไม่ปรากฏในแอปจริง
4. **คำในใบงานอาจกำกวม** — "แอป" คำเดียวอาจหมายถึงระบบไหนก็ได้ ให้ดูคำใบ้: ธุรกิจ (โรงน้ำ/คาเฟ่), ฟีเจอร์ที่พูดถึง (สต๊อก/ปิดยอด=Old Days, สั่งน้ำ=ละกอน, ประกาศ/บอร์ด=เลขา, ออเดอร์ลูกค้า/OEM=ระบบขาย) — ไม่ชัวร์ = ถาม
