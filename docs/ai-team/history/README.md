# 📥 ประวัติงานนำเข้าจากภายนอก

โฟลเดอร์นี้เก็บ **บริบท/ประวัติงานเก่าของคุณปาล์มจากนอกระบบทีม AI** เช่น สรุปโปรเจกต์ที่เคยทำกับ ChatGPT,
บันทึกการตัดสินใจเก่า, สเปกระบบที่เคยออกแบบไว้ที่อื่น — เพื่อให้ทีม AI (โดยเฉพาะ `data` และ `apprentice`)
รู้เรื่องทั้งหมดที่คุณปาล์มเคยทำ ไม่ใช่แค่ที่เกิดใน repo นี้

## วิธีนำเข้า (สำหรับคุณปาล์ม)

**จาก ChatGPT:** เปิดแชทโปรเจกต์ที่สำคัญ → ขอให้ ChatGPT "สรุปโปรเจกต์นี้: ทำอะไร ตัดสินใจอะไรไว้ เพราะอะไร
เหลืออะไรค้าง" → ก็อปคำตอบมาส่งให้ทีม (วางในแชท Claude Code หรือส่งให้คุณเลขาในไลน์ก็ได้)
ทีมจะบันทึกเป็นไฟล์ `.md` ในโฟลเดอร์นี้ให้เอง

**ตั้งชื่อไฟล์:** `YYYY-MM-<เรื่อง>.md` เช่น `2026-05-pos-lineman-api.md`

**หัวไฟล์ควรมี:** ระบบ/ธุรกิจที่เกี่ยว · ช่วงเวลา · ที่มา (ChatGPT/อื่นๆ) · สถานะ (เสร็จ/ค้าง/พับ)

## กติกาสำหรับทีม AI

- ไฟล์ในนี้คือ "บริบทอดีต" — ของจริงปัจจุบันให้ยึด `systems-map.md` และโค้ดใน repo ก่อนเสมอ
- `apprentice`: เจอร่องรอยวิธีคิด/การตัดสินใจของคุณปาล์มในไฟล์พวกนี้ ให้สกัดลง Playbook (อ้างที่มาว่าไฟล์ไหน)
- ห้ามเก็บความลับการเงิน (ต้นทุน/กำไร/เงินเดือน) ลงไฟล์ในโฟลเดอร์นี้ — repo นี้ทีมเข้าถึงได้
