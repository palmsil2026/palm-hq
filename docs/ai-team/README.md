# 📖 คู่มือทีม AI ส่วนตัว — โรงน้ำละกอน & คาเฟ่

ทีม AI นี้คือ "พนักงานเฉพาะทาง" ที่ช่วยคุณทำงานของทั้งสองธุรกิจ แต่ละคนมีความเชี่ยวชาญต่างกัน เรียกใช้ได้ตลอดเวลา

## 👥 ทีมของคุณ

| ตำแหน่ง | ชื่อเรียก | ช่วยเรื่อง |
|---|---|---|
| 🗓️ เลขาฯ | `assistant` | อีเมล ปฏิทิน นัดหมาย สรุปงานประจำวัน |
| 🔍 นักวิจัย | `researcher` | หาข้อมูล สรุปเว็บ ดูคู่แข่ง แนวโน้มตลาด |
| ✍️ นักเขียน | `writer` | ร่างอีเมล เอกสาร บทความ ข้อความลูกค้า |

| 🎨 ดีไซน์/คอนเทนต์ | `content` | โพสต์โซเชียล โปรโมชั่น โปสเตอร์ |
| 📊 นักวิเคราะห์ | `analyst` | สรุป/วิเคราะห์ข้อมูล ทำรายงาน กราฟ |

## 🚀 วิธีเรียกใช้

**วิธีที่ 1 — พิมพ์งานที่ต้องการ (ง่ายสุด)**
พิมพ์บอกงานตรง ๆ ระบบจะเลือกแผนกที่เหมาะสมให้เอง เช่น:
- "สรุปยอดขายคาเฟ่เดือนนี้ให้หน่อย" → ไปที่ `analyst`
- "ร่างโพสต์โปรโมชั่นน้ำละกอนช่วงหน้าร้อน" → ไปที่ `content`
- "คิดต้นทุนต่อขวดน้ำให้หน่อย" → ไปที่ `finance`

**วิธีที่ 2 — ระบุแผนกตรง ๆ**
เช่น "ให้ `researcher` ช่วยหาราคาขวด PET จากซัพพลายเออร์ 3 เจ้า"

## 💡 ตัวอย่างงานที่สั่งได้จริง

### 💰 การเงิน (finance)
- "ทำตารางรายรับรายจ่ายโรงน้ำเดือนสิงหาคม"
- "คิดจุดคุ้มทุนของเมนูกาแฟใหม่ ต้นทุนแก้วละ 18 บาท ขาย 55"
- "รายจ่ายเดือนนี้ก้อนไหนสูงผิดปกติบ้าง"

### 📊 นักวิเคราะห์ (analyst)
- "สรุปออเดอร์น้ำสัปดาห์นี้ แยกตามพื้นที่ส่ง"
- "เทียบยอดขายคาเฟ่ 3 เดือนล่าสุด ทำกราฟให้ด้วย"
- "ช่วงเวลาไหนของวันที่คาเฟ่ขายดีที่สุด"

### 🎨 ดีไซน์/คอนเทนต์ (content)
- "วางแผนคอนเทนต์ IG คาเฟ่ 1 สัปดาห์"
- "ออกแบบโปสเตอร์โปรโมชั่นสั่งน้ำ 10 แถม 1"
- "คิดแคปชั่นเปิดตัวเมนูใหม่ 5 แบบ"

### 🗓️ เลขาฯ (assistant)
- "มีอีเมลอะไรต้องตอบด่วนบ้างวันนี้"
- "นัดประชุมซัพพลายเออร์สัปดาห์หน้า หาเวลาว่างให้ที"
- "สรุปงานที่ต้องทำวันนี้"

### 🔍 นักวิจัย (researcher)
- "หาคู่แข่งโรงน้ำในพื้นที่ ราคาขายเท่าไหร่บ้าง"
- "เทรนด์คาเฟ่ปีนี้มีอะไรน่าสนใจ"

### ✍️ นักเขียน (writer)
- "ร่างข้อความแจ้งลูกค้าเรื่องปรับราคาน้ำ"
- "เขียนคำขอบคุณลูกค้าประจำสำหรับส่งทาง LINE"

### 💻 นักเขียนโค้ด (coder)
- "เพิ่มปุ่มเลือกจำนวนน้ำในแอป LIFF"
- "แก้บั๊กตอนกดสั่งแล้วไม่ขึ้นยอดรวม"

## ⚙️ ทำให้ทีมช่วยได้แม่นขึ้น

1. **กรอกข้อมูลธุรกิจ** ในไฟล์ `CLAUDE.md` (ส่วนที่เขียนว่า _เติมข้อมูล..._) เช่น ยอดขายเฉลี่ย ต้นทุน เมนู พื้นที่ส่ง — ยิ่งละเอียด ทีมยิ่งช่วยเก่งขึ้น
2. **เชื่อม Connectors** — Gmail, Google Calendar, Google Drive เชื่อมไว้แล้ว ทีมเข้าถึงอีเมล/ปฏิทิน/ไฟล์ได้
3. **แชร์ไฟล์ข้อมูล** — วางไฟล์ Excel/Sheet ยอดขายไว้ใน Google Drive แล้วบอกให้ `analyst` หรือ `finance` ดึงมาวิเคราะห์

## 📋 บอร์ดรับงาน — ให้คนอื่นฝากงานให้คุณ

หน้า **`request.html`** คือฟอร์มให้คนอื่น (ทีมงาน/ลูกค้า/คนขับรถส่งน้ำ) ฝากงานมาหาคุณ
กรอกรายละเอียด แนบรูป ระบุความเร่งด่วน → ข้อมูลเข้า Google Sheet → เลขา (`assistant`) ช่วยจัดสรรให้

- แจกลิงก์ / ทำ QR code ติดหน้าร้านหรือท้ายรถส่งน้ำได้
- สั่งเลขาได้เลย เช่น *"สรุปงานที่ฝากเข้ามาวันนี้ เรียงตามความเร่งด่วน"*

📖 วิธีตั้งค่า backend (GAS + Sheet) และใช้งาน: `docs/ai-team/job-board.md`

## ⏰ ตั้งงานอัตโนมัติ (ถ้าต้องการภายหลัง)

สามารถตั้งให้ทีมทำงานเองตามเวลาได้ เช่น:
- สรุปยอดขาย + งานค้างทุกเช้า 8 โมง
- สรุปการเงินรวมทุกสิ้นเดือน
- เตือนสต็อก/ออเดอร์ทุกเย็น

บอกได้เลยว่าอยากตั้งอะไร แล้วจะช่วยเซ็ตให้ครับ

## 📌 หลักการทำงานของทั้งทีม

- ตอบเป็น **ภาษาไทย** เสมอ
- **แยกโรงน้ำกับคาเฟ่** ให้ชัดทุกครั้ง
- ใช้ **ตัวเลขจริง** ไม่เดา — ถ้าข้อมูลไม่พอจะบอกว่าต้องการอะไร
- เรื่องสำคัญ (เงิน, ส่งอีเมล, ลบไฟล์) **ถามยืนยันก่อนเสมอ**
