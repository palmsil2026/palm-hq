# ใบสั่งงานสำหรับแชท origin-hq: แอปทีมผลิตรับ "ค่า pH จากไลน์" ลงตาราง QCChecks

> ส่งต่อจากแชท palm-hq 02/11 · palm-hq ขึ้นฝั่งเลขาแล้ว (`2026-11-02a`) — ยิง `lineQc` มาแล้วทุกครั้ง แต่ตอนนี้แอปตอบว่าไม่รู้จัก action (เลขาจด log ไว้เฉย ๆ ไม่พัง)

## ทำไม
- ข้อมูลแชทกลุ่มฝ่ายผลิต 7/10–2/11: ตั้มส่งค่า pH เป็น **รูป + "ค่าน้ำphเช้านี้ครับ"** ใน 10 จาก 17 วันที่เดินเครื่อง · ไม่เคยพิมพ์ตัวเลข
- **ฟอร์มตรวจคุณภาพน้ำในแอปทีมผลิตใช้ครั้งเดียว** (QCChecks มีแถวเดียว 29/8) → คุณปาล์มให้ใช้หลัก "ไปหาเขาในไลน์ แล้วให้ระบบเก็บแทน" (PALM-WAY ข้อ 13)
- ตอนนี้เลขาอ่านค่าจากรูป ตอบรับ ทวง และเก็บไว้ฝั่งตัวเอง (`PH_LOG`) — **อยากให้ค่าไปอยู่ที่เดียวกับ QC ของแอป** (ห้องผู้บริหาร/รายงานคุณภาพจะได้อ่านที่เดียว)
- คุณปาล์ม 02/11: ตรวจวันละ 2 รอบ (เช้า/บ่าย) + ทุกครั้งที่เปลี่ยน/เติมสารปรับ pH (ตอนนี้ใช้โซดาแอช — บิล เวิลด์ เคมี 14/10)

## ทำ (production-app)
1. `doPost` รับ `action: "lineQc"` (รหัสเชื่อมเดียวกับ `lineChat` · ใช้ `withIdem("qc_" + messageId)` กันซ้ำ)
   ```
   body = { token, action:"lineQc", ph:Number, slot:"am"|"pm"|"chem", how:"photo"|"typed",
            sender:"ชื่อในไลน์", image:"ลิงก์ Drive (ถ้ามี)", messageId, at:ms }
   ```
2. เขียนแถวใหม่ใน `QCChecks` (ไม่แก้แถวเดิม): `staff` = sender (จับคู่ Staff_ID ได้ก็ใส่) · `ph` · `result` ตาม `QC_PH_MIN/MAX` ·
   `checklist` = "" (ไม่ได้ตรวจเช็คลิสต์ผ่านไลน์) · `note` = "จากไลน์ · " + (how=photo ? "เลขาอ่านจากรูป" : "พิมพ์เอง") + slot + ลิงก์รูป · `app` = "line"
3. **ห้าม `linePush`/broadcast ตอนค่าผิดปกติสำหรับแถวที่มาจากไลน์** — เลขาบอกในกลุ่ม (reply ฟรี) + แจ้งคุณปาล์มคนเดียวแล้ว · broadcast กินโควต้าไลน์ตามจำนวนเพื่อนทั้งหมด (โควต้าฟรี 300/เดือน เคยหมดแล้ว 20/10)
4. คืน `{ success:true, id, result }` · ผิดรูปแบบ = `{ success:false, error }`
5. ไม่ต้องทำ: `qcDaily` / เตือนในไลน์ — เลขาทวงแบบ reply ให้แล้ว (ถ้า trigger `qcDaily` เปิดอยู่ แนะนำปิด กันเตือนซ้ำ + กินโควต้า)
6. ขยับเวอร์ชันแอป · แจ้งกลับ palm-hq ว่าขึ้นแล้ว → palm-hq ดู log "ค่า pH … ลงแอปแล้ว ✓"

## ไม่ต้องแก้ฝั่ง palm-hq
เลขาส่ง payload ข้างบนอยู่แล้ว (`phToApp` ใน `secretary/Code.gs`) · คำตอบไม่ success = จด log ไม่กระทบการตอบในกลุ่ม
